Политика обработки персональных данных

Каркас политики для согласования с Законом РБ «О защите персональных данных». Замените на финальный текст оператора ПДн.

1. Оператор

{% if company.full_name %}{{ company.full_name }}{% else %}ООО «…»{% endif %}{% if company.unp %}, УНП {{ company.unp }}{% endif %}{% if company.legal_address %}, {{ company.legal_address }}{% endif %}. Контакт по вопросам ПДн: {% if company.email %}{{ company.email }}{% else %}COMPANY_EMAIL{% endif %}.

2. Какие данные обрабатываем

  • учётные данные регистрации (логин, хеш пароля);
  • контакты из обратной связи (имя, телефон, сообщение);
  • избранные объявления, параметры фильтров в кабинете;
  • технические данные (IP, cookie, User-Agent) в объёме, нужном для работы сайта;
  • платёжные идентификаторы провайдера (без хранения полных данных карт на сайте), если подключена оплата.

3. Цели и правовые основания

Исполнение договора / оферты, обратная связь, безопасность сервиса, исполнение требований законодательства. Согласие — где оно требуется отдельно.

4. Сроки, передача третьим лицам, права субъекта

Сроки хранения, перечень получателей (хостинг, мессенджеры поддержки, платёжный провайдер), порядок отзыва и удаления — заполнить по факту инфраструктуры.

5. Cookies

Необходимые: cookie сессии после входа в кабинет; настройки интерфейса могут храниться в браузере (localStorage). По согласию («Принять все» в баннере) подключается Яндекс.Метрика (аналитика, вебвизор) — cookie сервиса Яндекса. Отказ («Только необходимые») отключает Метрику; выбор сохраняется в браузере до очистки данных сайта.
